# Форма обратной связи

React-компонент `src/components/ContactForm.tsx` отправляет данные через официальный REST API EmailJS. Новых зависимостей нет.

## Настройка

Скопировать `.env.example` в `.env.local` и заполнить значения из EmailJS:

- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

Публичные параметры текущего сайта заданы в `.env.production`. Они не являются секретами. При смене аккаунта или ключей обновить этот файл либо в Vercel добавить новые значения в Settings → Environment Variables для Production (и Preview при необходимости), затем пересобрать сайт. Vite подставляет значения при сборке. Public Key доступен посетителю, это нормально для EmailJS. Private Key не используется и не должен попадать в код или VITE-переменные.

Шаблон EmailJS:

- Subject: `Александровский парк — сообщение от {{name}}`
- To Email: фиксированный адрес владельца сайта.
- From Name: `Александровский парк`
- From Email: Use Default Email Address.
- Reply To: `{{email}}`

Текст:

```
Новое сообщение с сайта «Александровский парк».
Имя отправителя: {{name}}
Электронная почта: {{email}}
Дата и время отправки: {{time}}

Сообщение:
{{message}}
```

Время формируется в часовом поясе Europe/Moscow с отметкой МСК. Данные отправляются только в заданный шаблон. Форма не задаёт получателя.

## Проверка

`npm ci`, `npm run build`, `npx tsc --noEmit`.

В браузере проверить пустые поля, некорректный email, загрузку/блокировку кнопки, успешную отправку и сброс полей, сохранение введённого текста при ошибке, мобильное меню и форму. Для сетевой ошибки нет автоматического повтора: запрос мог быть доставлен даже при потере ответа.

Ответ API об успехе означает принятие запроса EmailJS; получение письма отдельно подтверждается в почтовом ящике. Ограничение повторных кликов и интервал 5 секунд действуют в текущем экземпляре формы и не заменяют защиту сервиса от спама.
